# Hi 群消息排版 SOP

## 1. 适用范围

桥接任务回复和已授权定时通知。

## 2. 执行前

任务回复走应用机器人，定时通知走单独配置的 Webhook。只向来源群回复；自动接入新群仅由所有者真实 @触发。

## 3. 操作步骤

1. 先写结果，再写必要限制和下一步。用命名链接，不用本机路径冒充下载链接。
2. 通过格式化器拆分长消息；只在首段 @真实请求人，不 @全体。
3. 模型交正文给桥接，不直接发送第二份消息。桥接将结果与 outbox 同事务保存，重试复用原 operateCode。
4. 应用发送失败保留原通道，不回退到另一身份的 Webhook。查回执及来源群正文核对结果。

## 4. 验收

原群、机器人账号、请求人及正文标记一致；长消息不丢链接。HTTP 200 和“已发送”不能代替回读。

## 5. 异常处理

发送超时 → 查原操作码及消息 ID；权限失败 → 明确报告，不自动申请权限；原群无访问权 → 保留待发结果，不转发到别的群。
