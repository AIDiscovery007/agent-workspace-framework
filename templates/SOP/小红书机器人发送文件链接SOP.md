# 文件交付 SOP

## 1. 适用范围

已获网盘交付能力的成员上传本人产物；未开放上传时交付本机文件并说明范围。

## 2. 执行前

确认本人工作区、固定云目录、受限 `hi` 入口及 hi-pan Skill。代理使用部署所有者的云授权，不是成员独立云账号。

## 3. 操作步骤

1. 核对普通文件位于本人目录内，排除隐藏文件、凭据、浏览器状态、符号链接和硬链接。
2. 使用运行时 PATH、`login=false` 执行 `hi pan:config --get-default-folder`，取得固定目录。
3. 执行 `hi utils:generate-operate-code`，保存原操作码，再用 `hi pan:write --file-path <本人文件绝对路径> --folder-path <固定目录> --operate-code <原码>`。
4. 回读该入口产生的本人 entryId，核对名称、字节大小、ACTIVE 状态和 HTTPS 分享链接，再将命名链接交桥接回原群。

## 4. 验收

上传文件与本机产物一致、远端元数据通过；群回复与接收方下载另行验证。跨账号文件、目录和操作码被拒绝。

## 5. 异常处理

写入超时 → 保留原码重试并回读；目录歧义 → 停止，不改全局目录；未授权方法或外部资源 → 拒绝；代理不可用 → 报告实际阻塞，不改用全局 CLI 绕过。
