# 从实际项目提炼了什么

基线：2026-11-13 当前运行项目。只抽取源码、测试、操作不变量与可复用规则，未导出实际状态库、错题原文、群消息、成员工作目录、凭据或业务产物。

| 原体系 | 公共化结果 |
| --- | --- |
| 根 AGENTS 与几十个业务约定 | 保留指令/SOP/Skill 分层、业务归档、真实身份和授权边界 |
| 共享错题本 | 保留 candidate→assess→group→triage→开发/测试/验收→归档，以及稳定键/范围门槛 |
| 守墓人 | 采用当前优先级机制，首次即可治理；原守墓人亲自测试、全部闭环才归档 |
| 日报/周报/整理 | 复制当前执行器、来源验证、日期依赖、幂等写入和准确会话清理，改为配置驱动 |
| 成员空间与权限 | 保留真实 Codex 权限和受限工具代理，去掉历史账号特例，默认未绑定成员拒绝 |
| Hi 多群/多成员 | 保留 WS/轮询、规范消息回读、权限重验、串行队列与来源群交付 |
| SOP 沉淀 | 五段操作模板、同主题更新、根短索引、隔离成员只写本人索引 |
| 文件与通知 | 业务交付和定时通知身份分开，凭据按用途本机配置，外部写入后回读 |

旧分发包的“同源三次才治理”“开发自行测试/部署”等描述与当前运行规则不一致，公共版按当前源码与 SOP 修正。保留原始源文件的 SHA256 于 [来源清单](source-manifest.json)，便于追溯抽取基线。

个人角色称呼、个人周报文风、企业评测业务 Skill、原群和网盘目录、COS 规则、具体业务 SOP 不属于通用框架，不将其私有内容公开。需要 COS 时由部署者提供自己的规则和适配器，当前仓库不暗含作者存储桶或上传授权。
