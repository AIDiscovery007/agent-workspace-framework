# 复现验收矩阵

复现完成是“所启用范围的全部必要项有本次真实证据”。每项使用 passed / failed / pending / not-enabled；pending 不能计入通过。复制 `config/acceptance.example.json` 到部署目录，填实际证据路径，不提交生产回执到公共 Git。

| ID | 范围 | 可观察结果 | 自动/真实边界 |
| --- | --- | --- | --- |
| CORE-01 | 初始化 | 新目录完整生成，凭据/服务为空，重复 init 不改状态 | verify 的全新临时部署 |
| CORE-02 | 指令与 SOP | Skill 可读、所有链接解析，SOP 五段结构，索引对应 | release_check |
| CORE-03 | 错题账本 | 候选收录、重复键同 ID、并发不丢；范围/时间/敏感字段拒绝 | notebook 回归 + demo |
| AUTH-01 | 成员文件 | 本人可写、共享只读、他人/主目录不可读；软硬链接拒绝 | 配置回归 + **实际 Codex 沙箱探针** |
| AUTH-02 | 会话与能力 | 新建/恢复 profile 正确，同人跨群 browser 相同、不同人不同 | 回归 + 真人任务 |

## 版本与证据

公共仓库 CI 只验证可移植源码、合成夹具和可检查契约；不包含任何组织 Hi、浏览器登录、用户模型额度或 Herdr 实例。不要把 CI 绿灯称作全部外部项通过。

每次正式部署记录 Python/Node/Codex/Hi/Herdr 版本、配置指纹、目标根、实际启用项和证据时间。凭据和群内容保持本机，公开报告只写范围/数量/结果。外部调用写入后用实际对象回读；脚本退出码和模型自述不能替代。
